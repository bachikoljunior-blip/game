設定ファイル1枚で、自分のブランドの放置ゲームになる

お客さんに「もう一度サイトを開く理由」を作るための、小さなブラウザゲームです。 キャンペーンページ、店舗サイト、配信者のリンク集、展示会のノベルティ。置くだけで動きます。

まず遊んでみる（珈琲店の例） 設定ファイルを作ってみる

どちらも登録不要・無料です。生成した設定はどこにも送信されません。

何を書き換えるのか

この1ファイルだけです。ゲーム側のコードは触りません。

{
  "meta":     { "title": "まめや珈琲 焙煎クリッカー", "faviconEmoji": "☕" },
  "theme":    { "background": "#1a1410", "accent": "#c98a3c" },
  "currency": { "name": "焙煎豆", "unit": "g", "emoji": "🫘" },
  "tapTarget":{ "emoji": "☕", "label": "豆を煎る" },
  "generators": [
    { "id": "g1", "emoji": "🔥", "name": "手回し焙煎機",
      "baseCost": 15, "baseRate": 0.2 }
  ]
}

上の「設定ファイルを作ってみる」を開けば、これを手で書かずに作れます。 値段と毎秒の量（＝遊びの速さ）は釣り合いを取った既定値が入るので、名前を変えるだけで成立します。

技術的なこと

  • ビルド不要。フォルダを置くだけです。Node も PHP も要りません
  • 外部ライブラリなし・通信なし。あなたが設定したリンク以外へは何も送りません
  • セーブは端末内（localStorage）。サーバーもデータベースも不要
  • スマホ縦画面前提。片手・タップだけで遊べます
  • GitHub Pages / Netlify / Cloudflare Pages / 自社サーバー、どこでも動きます
